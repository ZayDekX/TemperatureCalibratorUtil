# TemperatureCalibratorUtil

Небольшое WPF-приложение для калибровки [температурной системы](https://github.com/AcademVac/ModbusEmulator)

## Сборка
```ps
git clone https://github.com/ZayDekX/TemperatureCalibratorUtil
cd TemperatureCalibratorUtil
dotnet build
dotnet run
```

## Настройка

При первом запуске приложение автоматически создаёт новый файл конфигурации `config.json` рядом с исполняемым файлом.

| Группа | Назначение |
| --- | --- |
| Device | Настройки подключения к Modbus устройству |
| Charts | Настройки отображаемых графиков |
| System | Настройки модели |
| Parameters | Настройки параметров системы, передаваемых через Modbus |
| Logging | Настройки логирования значений в CSV |

### Device

| Свойство | Назначение |
| --- | --- |
| Port | Порт устройства |
| Host | Адрес устройства |

### Charts

Представляет собой коллекцию из объектов

| Свойство | Назначение |
| --- | --- |
| Name | Отображаемое название графика |
| ParameterId | Id параметра со значением |
| ErrorId | Id параметра, означающего ошибку датчика |

### System

| Свойство | Назначение |
| --- | --- |
| PidController | Настройки ПИД-регулятора, вычисляющего уставку температуры нагревателя |
| TargetTemperature | Стандартная целевая температура системы |
| UpdatePeriod | Период обновления системы |
| SystemTemperatureParameterId | Id параметра текущей температуры системы (ввод) |
| HeaterTemperatureParameterId | Id параметра текущей температуры нагревателя (ввод) |
| EnvironmentTemperatureParameterId | Id параметра температуры окружающей среды (ввод) |
| PressureParameterId | Id параметра давления (ввод) |
| TargetHeaterTemperatureParameterId | Id параметра целевой температуры нагревателя (вывод) |
| HeaterStateParameterId | Id параметра |
| MinStabilityFrameCount | Минимальное количество кадров системы, позволяющее считать систему стабильной на целевом значении |
| StabilityTolerance | Погрешность определения стабильности системы |

PID Controller

| Свойство | Назначение |
| --- | --- |
| Kp | Пропорциональный коэффициент |
| Ki | Интегральный коэффициент |
| Kd | Дифференциальный коэффициент |
| DFilterCoeff | Коэффициент экспоненциального сглаживания дифференциального коэффициента |
| MinOutput | Минимальное результирующее значение |
| MaxOutput | Максимальное результирующее значение |

### Parameters

| Свойство | Назначение |
| --- | --- |
| Input | Вводимые параметры (чтение по Modbus) |
| Output | Выводимые параметы (запись по Modbus) |

Настройки параметра

| Свойство | Назначение |
| --- | --- |
| Device | Id устройства Modbus |
| Address | Адрес ячейки со значением |
| Name | Название параметра |
| Multiplier | Множитель значения |

### Logging

| Свойство | Назначение |
| --- | --- |
| Separator | Разделитель значений |
| FileName | Название файла в который будут записаны значения |
| Enabled | Включить логирование (изначально включено) |
